CAR-T QSP Model: Follow-up Analyses

B. Ma
April 2026

Overview

Three follow-up analyses building on the Part 1 report:

  1. Reparameterization — resolve the β/X₀ structural identifiability degeneracy by rescaling to a single effective parameter ρ = β/X₀.

  2. Tipping-point search — bisect to find the critical antigen-low fraction at which outcome flips from control to exhaustion-driven escape.

  3. Global sensitivity (Sobol) — complement the local AD gradient with variance-based sensitivity indices across the realistic parameter range.

Part 1: Reparameterization — ρ = β/X₀

Theoretical derivation

The exhaustion dynamics in the current model are

\[ \frac{dX}{dt} = \beta \cdot s_{\text{raw}}(E, T) \cdot \frac{T_{\text{total}}}{K_{\max}} - k_{\text{recov}} X \]

\[ s_{\text{eff}} = s_{\text{raw}} \cdot \exp\!\left(-\frac{X}{X_0}\right) \]

Introduce the dimensionless variable $Y = X/X_0$. Then $\frac{dX}{dt} = X_0 \frac{dY}{dt}$, so dividing through by $X_0$:

\[ \frac{dY}{dt} = \frac{\beta}{X_0} \cdot s_{\text{raw}} \cdot \frac{T_{\text{total}}}{K_{\max}} - k_{\text{recov}} Y \]

\[ s_{\text{eff}} = s_{\text{raw}} \cdot \exp(-Y) \]

Define $\rho \equiv \beta/X_0$. The rescaled system depends on ρ and $k_{\text{recov}}$, not on β and X₀ separately. For the reference parameters (β = 1.0, X₀ = 0.08), the identifiable ratio is ρ = 12.5.

This is why the local sensitivity returned exactly equal-and-opposite values for β and X₀: any change in β is indistinguishable from a compensating change in X₀. Only their ratio affects outcomes.

Reparameterized model

We rewrite the ODE using ρ directly, with X now interpreted as "exhaustion relative to threshold" (X₀ ≡ 1 implicit).

Part 2: Tipping-point search

The pretreated/heavy scenario (Tlow fraction = 0.40) ran away to carrying capacity via exhaustion feedback. Typical MM (Tlow = 0.10) achieved deep remission. Somewhere between these lies a tipping point where the balance between kill and exhaustion accumulation flips.

Isolating the causal variable

We fix Thigh at 0.30 (pretreated-like) and scan Tlow from 0 to 0.65, with Tmid = 0.70 − Tlow. This isolates the antigen-low burden as the scan variable while keeping total tumor at 10¹¹ cells.

Clinical interpretation

At Thigh = 0.30 of a 10¹¹-cell baseline tumor, the threshold occurs at roughly flow ≈ (see output above). Below this fraction, the reserve kill capacity against the antigen-low stratum exceeds the exhaustion accumulation rate, and the system achieves control. Above it, exhaustion outpaces kill and the T_low compartment rebounds to carrying capacity.

This gives a biomarker-actionable number: if pre-treatment flow cytometry quantifies the antigen-low fraction, the model predicts whether standard-dose CAR-T will suffice or whether dose escalation / alternative approaches should be considered.

Part 3: Global sensitivity — Sobol indices

Local AD sensitivity gives the instantaneous effect of each parameter at the reference point. Sobol indices give the variance contribution of each parameter across a realistic operating range — capturing nonlinear and interaction effects that linear gradients miss.

Parameter count: 14
Reference ρ = 12.50 is inside [6.25, 25.00]

Sobol sampling

With N = 128 base samples and 14 parameters, Sobol requires N·(d+2) = 128·16 = 2048 simulations for first-order, and an additional N·d = 1792 for total-order indices. At ~0.3s per simulation, expect ~10–15 minutes total.

For a fast preview, use N = 64 (~1024 sims, ~5 min). For publication quality, N = 512+ is preferable.

Interpretation:

  • S1 (first-order): fraction of output variance explained by that parameter alone, averaged over the others.

  • ST (total): fraction of variance including all interactions with other parameters.

  • ST − S1: interaction effects. Large values indicate the parameter's effect depends on other parameters' values.

If local and global rankings roughly agree, the model's behavior is well-approximated by linear sensitivity at the reference point. If they disagree, there are strong nonlinearities or interactions — parameters that look unimportant locally may matter over the realistic range, or vice versa.

Closing

Three deliverables:

  1. Reparameterization folds β and X₀ into their only identifiable combination ρ = β/X₀, eliminating the structural degeneracy. Future fits to patient data should use ρ as the free parameter.

  2. Tipping-point search via bisection pins down the critical f_low value — a biomarker-actionable threshold relating pre-treatment antigen heterogeneity to CAR-T outcome.

  3. Global Sobol sensitivity complements the local AD gradient with variance-based importance across the realistic parameter range, quantifying interaction effects invisible to first-order analysis.

Residual questions:

  • Does ST − S1 identify which pairs of parameters interact? (Would require second-order Sobol indices: Sobol(order=[0,1,2]).)

  • How does the tipping point flow* shift under different Thigh (pretreated vs naïve)? (2D scan over (Thigh, Tlow).)

  • Is the Sobol ranking stable under changes in parameter bounds? (Run the analysis at different bound widths — ±50% vs ±2x.)
